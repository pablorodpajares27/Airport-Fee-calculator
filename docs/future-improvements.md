# Future Improvements

The current prototype is functional, but several improvements could be added in future versions.

---

## 1. Full AI Automation

At the moment, the AI structuring step is semi-manual.

A future version could connect directly to an AI API, a local large language model or a structured output system using JSON Schema.

---

## 2. Graphical User Interface

The current version runs in the command line.

A future interface could include airport selection menus, form-based input fields, PDF preview, fee breakdown tables and exportable reports.

---

## 3. More Robust JSON Schema

The JSON structure could be formalized with a strict schema to improve validation, consistency across airports, error detection and compatibility with future interfaces.

---

## 4. Batch Airport Processing

The system could process many airports automatically, generating structured data and validation reports for each one.

---

## 5. Route Analysis Tools

Once airport charges are standardized, the system could be extended to compare multiple airports and support route planning decisions.

Possible features:

- airport-to-airport fee comparison;
- cost sensitivity by aircraft type;
- passenger scenario simulation;
- seasonal fee analysis;
- route cost estimation.

---

## 6. Exportable Reports

The calculator could generate PDF reports, Excel files, JSON calculation logs or CSV summaries.

---

## 7. Error and Confidence Scoring

Future versions could include confidence levels for AI-generated rules, especially when source documents contain ambiguous tables or exceptions.
