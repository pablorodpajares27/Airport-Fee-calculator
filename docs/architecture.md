# Architecture

The Airport Fee Calculator is organized as a modular pipeline with three main programs.

---

## Program 1 — AI Prompter

Responsible for preparing airport documentation for AI-assisted structuring.

Main responsibilities:

- scan the airport folder structure;
- detect available PDF files;
- identify airports with missing or multiple PDF files;
- normalize PDF file names;
- extract readable text from PDFs;
- generate a customized AI prompt for each airport;
- create the input material required for the JSON generation step.

Output:

- normalized PDF files;
- extracted text file;
- customized AI prompt.

---

## Program 2 — JSON Processor

Responsible for validating and storing the JSON generated by the AI step.

Main responsibilities:

- read the AI-generated JSON;
- clean common formatting issues;
- validate required fields;
- check that the JSON airport and country match the selected airport;
- save the JSON file in the correct airport folder.

---

## Program 3 — Fee Calculator

Responsible for using the structured data to calculate airport charges.

Main responsibilities:

- allow the user to select a country and airport;
- open the official PDF documentation for reference;
- load the airport JSON file;
- ask the required operational questions;
- evaluate conditions and formulas;
- calculate charge components;
- display a detailed fee breakdown;
- display the final total.

---

## High-Level Data Flow

```text
PDF documentation
   ↓
Text extraction
   ↓
Prompt generation
   ↓
AI-generated JSON
   ↓
JSON validation
   ↓
Rule engine
   ↓
Fee breakdown
```

---

## Design Principle

The main design goal is to separate the project into independent stages: document preparation, data structuring, validation and calculation.
